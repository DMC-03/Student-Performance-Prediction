# Student Performance Prediction System

ML model to predict student grades and provide personalized feedback.

## Tech Stack
Python, Scikit-learn, Decision Tree Classifier, Gradio, Pandas, NumPy

## Features
- Predicts student grade from academic and behavioral inputs
- Personalized improvement feedback
- Interactive Gradio UI

## How to Run
pip install -r requirements.txt
python train_model.py
python app.py
